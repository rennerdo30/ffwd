Privacy

This website

This site sets no cookies, uses no analytics and loads nothing from other sites except one request: your browser asks the public API of the code host for the list of ffwd releases, so the download links point at the newest version. The host receives that request like any other visit. The site itself is served as static files by the same host, which keeps its own server logs.

The ffwd app

ffwd has no account and no telemetry. It talks to the Git remotes you work with, checks for updates against ffwd's release list (and downloads an update when you install one), and, only if you configure one, sends requests to your AI endpoint. Before any AI request is sent you see exactly what it contains.

You can turn the update check off in Settings → Updates, or with check = false in the [update] section of the settings file.
